# ADR-0001: Alcance de la Fase 0

- Estado: Propuesta pendiente de validación
- Fecha: 2026-11-09

## Contexto

El proyecto necesita una base reproducible antes de implementar el dominio editorial. Las decisiones de framework, versiones y despliegue afectan seguridad, pruebas y mantenimiento.

## Decisión propuesta

La Fase 0 entregará gobierno del repositorio, documentación, configuración de ambientes, CI mínima y un esqueleto ejecutable, sin funcionalidades de noticias. Las decisiones tecnológicas concretas se registrarán en ADR separados y no se asumirán como definitivas sin validación.

## Consecuencias

Se reduce el riesgo de construir sobre decisiones implícitas. La implementación de la Fase 1 queda condicionada a cerrar framework PHP, versiones, licencia y modelo de permisos.
