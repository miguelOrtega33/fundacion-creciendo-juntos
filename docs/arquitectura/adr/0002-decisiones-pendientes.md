# ADR-0002: Decisiones técnicas pendientes

- Estado: Pendiente

Antes de implementar código productivo se debe decidir y registrar:

1. Framework PHP y versión soportada.
2. Versión de MySQL y estrategia de migraciones.
3. Servidor web y modo de ejecución PHP.
4. Herramientas de pruebas de navegador y accesibilidad.
5. Licencia del repositorio.
6. Proveedor de correo y política de retención.
7. Modelo detallado de roles y permisos.

No se deben introducir dependencias ni servicios que resuelvan estos puntos sin ADR o aprobación explícita.
