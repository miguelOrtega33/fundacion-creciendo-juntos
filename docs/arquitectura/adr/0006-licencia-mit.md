# ADR-0006: Licencia MIT

- Estado: Aprobado
- Fecha: 2026-11-09

## Decisión

El repositorio se distribuirá bajo licencia MIT. El texto completo se encuentra en `LICENSE`.

## Motivo

La licencia MIT es apropiada para un proyecto de portafolio que busca permitir reutilización, manteniendo una obligación de atribución y el aviso de licencia.
