# Plan de implementación

0. Decisiones base: framework, versiones, licencia, modelo de permisos y diseño visual.
1. Fundación técnica: Docker, configuración, base de datos, logging y CI.
2. Identidad y permisos: usuarios, sesiones, recuperación y autorización.
3. Dominio editorial: noticias, categorías, estados, auditoría y comentarios.
4. Portal público: listado, destacadas, búsqueda, paginación y URLs.
5. Editor y multimedia: editor visual, sanitización, cargas y vista previa.
6. Paneles y notificaciones: experiencias por rol y avisos internos.
7. Endurecimiento: seguridad, accesibilidad, responsive, rendimiento y documentación.
8. Preparación de entrega: matriz completa, evidencias reproducibles y guía de despliegue.

Cada fase tendrá issue, rama, PR, pruebas y evidencia. No se inicia la Fase 0 sin aprobación.
